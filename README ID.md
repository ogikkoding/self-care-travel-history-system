## 📖 Deskripsi

**Peduli Diri** merupakan aplikasi berbasis web yang dirancang khusus untuk membantu pengguna mencatat dan memantau riwayat perjalanan harian mereka sebagai bentuk pencegahan serta mitigasi penyebaran Covid-19. 

Dengan aplikasi ini, pengguna dapat mencatat lokasi yang dikunjungi, tanggal, waktu, suhu tubuh, hingga kelurahan. Seluruh data riwayat perjalanan akan tersimpan dengan rapi dan aman di dalam basis data berbasis teks (`.txt`).

---

## ✨ Fitur

- 🔐 Login & Register Pengguna (NIK & Nama Lengkap)
- 📊 Dashboard Utama
- 📝 Catat Perjalanan (Tanggal, Jam, Lokasi, Suhu Tubuh, & Kelurahan)
- 📋 Riwayat Perjalanan (Tabel Histori Kunjungan)
- 🚪 Logout Sistem

---

## 🚀 Cara Kerja Sistem

1. Pengguna melakukan Registrasi menggunakan NIK dan Nama Lengkap atau langsung Login jika sudah terdaftar.
2. Masuk ke halaman utama (Dashboard) aplikasi Peduli Diri.
3. Pengguna memilih menu Catat Perjalanan untuk memasukkan data tanggal, jam, lokasi, suhu tubuh, dan kelurahan saat berkunjung ke suatu tempat.
4. Sistem secara otomatis memproses dan menyimpan data tersebut ke dalam file teks (`.txt`) di server.
5. Pengguna dapat melihat seluruh rekam jejak perjalanan pada menu Catatan Perjalanan kapan saja.
